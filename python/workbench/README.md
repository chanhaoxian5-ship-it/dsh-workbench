# 托管服务与Agent接口的维护源

这里的三个Python文件是插件扩展的维护源。构建脚本将它们复制到`backend/workbench`；实际运行时使用后者。因此修改后应执行`python scripts/build_bundle.py`，不要只改生成副本。

| 文件 | 负责什么 | 不负责什么 |
|---|---|---|
| `managed.py` | 启动本机HTTP后端、同目录单实例锁、高位端口、endpoint记录、认证关闭及短期票据。 | 不执行Agent任务，不迁移旧库，不自动删除数据。 |
| `agent.py` | DSH工具和MCP共享的4个工具定义与调用逻辑；白名单查询、服务身份核对、可靠项目/发现发布。 | 不扫描全部资料，不额外存数据库，不替模型生成科学结论。 |
| `mcp.py` | MCP stdio协议与`--call`单次调用模式；握手、工具发现、调用、输入长度和错误封装。 | 不监听第二个端口，不自行唤起已关闭的后端，不将stdout当普通日志。 |

新增工具时，先在agent.py定义并实现，再确认DSH参数DSL与MCP JSON Schema都能表达它的输入，最后构建、测试并更新Agent文档。协议成功不等于业务事实正确，写入仍须核对回执与确切修订。
