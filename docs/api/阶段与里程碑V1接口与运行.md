# 阶段与里程碑 V1

2026-11-03。本轮实现后端契约与概览读取接口，沿用数据库结构 v3、请求 schema_version=1。没有新表或破坏性迁移；旧数据不回填推测日期。前端双轨组件尚未调用本接口，DSH 插件仍为逐条文件/记录交付 V0。

## 阶段写入

`POST /v1/workspaces/{workspace_id}/stages`，认证及本机访问保护与既有项目接口一致：

```json
{
  "schema_version": 1,
  "operation_key": "stage-review-register-1",
  "expected_version": 0,
  "item": {
    "id": "stage-review",
    "kind": "stage",
    "title": "导师意见",
    "archived": false,
    "data": {
      "status": "completed",
      "date": null,
      "summary": "仅为结构示例；实际录入时填写依据与范围。",
      "refs": [{"id": "review-document", "kind": "artifact", "version": 1, "role": "source"}]
    }
  }
}
```

必须先登记引用的文件或工作记录。阶段状态为 `completed/current/planned/unknown`，由录入者声明，不根据时间或任务数计算。`date` 必须是严格 YYYY-MM-DD 或 null；未来日期不自动等于 planned，过去日期不自动等于 completed。至少一个 `source`（artifact/source）或 `context`（record）引用；引用必须在同一工作空间，未指定修订时在事务内固定到当时的修订。

阶段支持列表、详情、历史修订与搜索：

- `GET /v1/workspaces/{w}/stages?include_test=true&limit=30&before={sequence}`
- `GET /v1/workspaces/{w}/stages/{id}?version=1`
- `GET /v1/project-items?kind=stage`、`GET /v1/search?q=...`

列表默认排除测试空间。精确空间/记录 ID 读取沿用既有行为，可读取测试记录；这不是额外的权限隔离。

## 里程碑写入

继续写入 `POST /v1/workspaces/{w}/versions`。`label/status/summary/refs` 仍为必填；新字段均为可选，旧请求继续有效：

```json
{
  "schema_version": 1,
  "operation_key": "milestone-review-1",
  "expected_version": 0,
  "item": {
    "id": "milestone-review",
    "kind": "version",
    "title": "按导师意见修改后的版本",
    "archived": false,
    "data": {
      "label": "v2",
      "status": "draft",
      "summary": "结构示例，不表示真实稿件已修改。",
      "occurred_on": null,
      "milestone_status": "recorded",
      "stage_version": true,
      "refs": [
        {"id": "stage-review", "kind": "stage", "version": 1, "role": "stage"},
        {"id": "manuscript-file", "kind": "artifact", "version": 1, "role": "artifact"}
      ],
      "changes": [{
        "artifact_id": "manuscript-file",
        "artifact_version": 1,
        "file": "Manuscript.docx",
        "title": "补充方法说明",
        "summary": "第2节补充方法适用条件。",
        "kind": "semantic",
        "source": "user",
        "note": "用户注释原样放在这里。"
      }]
    }
  }
}
```

`occurred_on` 与接收时间分开。`milestone_status=recorded`（默认）表示登记为已发生事实，`planned` 表示预计，其日期是计划日期，界面不得显示成已经发生。`status` 继续表示稿件自身的 draft/in_review/submitted/archived 声明，不和里程碑时间状态混用。旧记录没有日期时，读取结果明确 unknown。

一个里程碑最多一个 role=stage 引用，归属仅保存在该引用。`stage_version=true` 表示阶段产出，必须有所属阶段且不能是 planned。同一阶段稳定 ID 在所有未归档里程碑中最多有一个阶段产出，跨阶段修订也执行同一规则。替换时须先通过新修订取消旧标记，再指定新产出；当前逐条接口不保证两次操作间无空窗。旧修订继续保留原标记。未约束每个项目只能有一个 current 阶段。

每条 changes 必须指向本里程碑 refs 中的确切 artifact ID 与修订号。`file` 是展示文字，身份依赖 ID/修订，不依赖文件名。`kind=semantic/format/mixed`，`source=agent/user`，`note` 为原样字符串或 null；每版最多100条。自填 user 不等于人工认证，后端不生成语义解释，也不把说明当成机械 diff 的结果。

2026-11-03复核补充：同一版本的artifact角色引用，每个artifact ID只能登记一次。重复同一修订或同时登记多个修订均返回409 `ambiguous_artifact_reference`。旧的歧义记录不自动改写，版本比较会明确返回同一错误，避免漏掉其中一个修订。

新增字段缺失时，不改写历史 body；board 返回 null/false/空数组等明确缺省。更新已有里程碑仍需提交完整 data，并提供 expected_version；需要保留的字段应原样带回。

## 概览读取

`GET /v1/workspaces/{w}/board?limit=30&before={sequence}`。

一次 SQLite 读取事务返回：

- `workspace`：空间与 is_test 分类。
- `stages`：最多100条未归档阶段的当前修订，先按登记序号选取，再按业务日期排序，未知日期置后；超出时 `stages_truncated=true`。必须显示范围受限提示，并用 stages 列表分页读取剩余阶段。
- `milestones`：未归档里程碑，按稳定登记序号倒序分页（limit 1–100）。`next_before` 为空表示本轮末页；这不是按业务日期截取，客户端收齐分页后再进行时间轴布局。后续页面各有自己的读取快照，不承诺跨请求快照固定。
- 每个里程碑含原始 `version`、确切登记修订的 `stage`、`files`、日期/标记/changes。stage 缺失时为 null，日期缺失时 `date_status=unknown`。不能用样例、接收时间或 mtime 补齐。
- `stage/files` 包含 current_version/current_archived，既可还原当时登记依据，也可辨别引用对象后来变化。归档阶段不出现在 stages 当前列表，但旧里程碑仍返回确切阶段修订。
- 文件返回 `storage=reference_only`、`file_verification=not_performed`。读取 board 不访问磁盘；实际存在/指纹检查使用既有 artifacts/{id}/inspect?version=N，文本预览使用 preview。指纹及登记修订不代表已经保存了文件内容。
- 有 changes 时 `changes_status=producer_declared_not_authenticated`，否则 `not_recorded`。不推导总体完成率、导师认可或投稿确认。

旧 `/overview` 计数和近期记录接口保持可用，counts 可以新增 stage 类别。`/capabilities` 增加 stages/project_board 模块，database_version 仍为3。

## 可靠发布与错误

既有 `scripts/publish-project.ps1 -Collection stages -Workspace {w} -Payload {json}` 自动支持阶段，仍查询原操作键/回执并读回确切修订。接口示例中的 ID 必须替换为已登记实际记录，不能直接写入日常库。

同键同内容重投返回原回执，不新增修订；同键不同内容409。缺失/跨空间/错误类型引用409；非法数据和不匹配角色422；阶段产出竞争409 `stage_output_conflict`；版本竞争409 `version_conflict`。失败不留下正式项目操作或成功回执。认证失败401，未知查询参数400。
