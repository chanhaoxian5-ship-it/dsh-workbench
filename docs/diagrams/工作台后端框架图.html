API SURFACE

接口清单

以下是业务接口，支持管理/项目 Bearer 或浏览器会话；项目凭证逐接口限制范围。{w}为workspace_id；collection = artifacts / versions / feedback / plans / tasks / records / canvases / stages / sources。POST sources被拒绝；用refresh生成来源快照。GET /静态外壳和资源白名单另行处理，OPTIONS跨域预检由接入层处理。

通用规则
limit通常为1–100；before为稳定序号游标。未知或重复query参数拒绝。常规列表默认排除测试记录，精确ID读取仍可读取测试项。接口返回的schema_version为1，数据库user_version为3，记录version是各自修订号。
