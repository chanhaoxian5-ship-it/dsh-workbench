# 文档导航

| 文档 | 适合谁看 | 内容 |
|---|---|---|
| [INSTALL.md](INSTALL.md) | 安装、运行或更新插件的人 | 环境要求、DSH安装、配置字段、独立数据目录、旧库一致备份接入、MCP配置与回退。 |
| [AGENT_GUIDE.md](AGENT_GUIDE.md) | DSH或其他Agent | 如何确定项目/来源、读取资料、填写v1契约、保留幂等键、核对回执、处理未知与冲突。也是DSH随包可加载操作规程的正文。 |
| [VALIDATION.md](VALIDATION.md) | 想判断完成程度或排查问题的人 | 分别记录亲自实测、代码依据和未验收边界，避免把隔离测试当成日常部署成功。 |
| [api/](api/) | 对接HTTP或修改后端的人 | 发现、变化、项目、阶段/里程碑的详细字段与接口；含合成JSON样例。插件启动方式仍以INSTALL为准。 |

查源码入口请看根目录README的“目录与文件说明”，各源码目录还带自己的README，说明具体文件职责和应在哪里修改。GitHub文件列表中间的文字是该路径最近一次提交说明，长期有效的文件介绍以这些文档为准。
