# 随包后端与工作台前端

这个目录是插件实际启动的Python包。网页资源位于[web](web/)，与后端由同一本机HTTP服务提供，不需要另起一个前端服务器。

| 文件 | 职责 |
|---|---|
| `server.py` | HTTP服务与请求入口；提供白名单静态文件，检查Host、Origin、Bearer令牌、JSON及请求长度，分发API并返回结构化错误。 |
| `contracts.py` | 发现交付的输入契约与通用校验：身份、来源、生产会话、时间、路径、内容摘要等。校验通过不表示科学内容已被认证。 |
| `store.py` | 初始化SQLite与发现存储；保存发现、修正链、投递键和回执，提供列表、详情与首页读取。 |
| `changes.py` | 重要变化及知晓/稍后状态；把证据版本与用户关注状态版本分开，并保护并发修改。 |
| `project_http.py` | 项目资料路由；把workspaces、各资料集合、board、search、inspect等请求映射到业务方法。 |
| `project_contracts.py` | 工作空间和9类项目资料的字段/类型契约，以及refs、阶段、版本变更说明、画布坐标等规则。 |
| `projects.py` | 项目业务与修订；解析固定引用，检查任务依赖、阶段产出和反馈依据，保存历史，组装概览与版本比较。 |
| `project_files.py` | 受限只读文件访问；检查项目根目录内的路径、文件状态和指纹，提供有界MD/DOCX文字预览。 |
| `publish.py` | 发现可靠发布客户端；保留原投递键重试，核对回执及发现读回，避免超时后盲目重复登记。 |
| `project_publish.py` | 项目资料可靠发布客户端；校验操作摘要、资源身份、确切修订和来源快照完整集合。 |
| `maintenance.py` | 数据库检查、一致备份与新目录恢复；核对必要表/列、SQLite完整性和外键关系。 |
| `managed.py` | 插件托管入口：单实例锁、高位端口绑定、endpoint发现、认证启停、短期单次浏览器连接票据。 |
| `agent.py` | DSH工具和MCP共用的Agent接口；限制读取路径，并复用可靠写入客户端。 |
| `mcp.py` | stdio MCP与单次工具调用入口；处理握手、工具列表、调用和结构化结果，不额外开网络端口。 |
| `__init__.py` | Python包入口标记，本身不启动服务或读取项目资料。 |

`managed.py`、`agent.py`、`mcp.py`由[python/workbench](../../python/workbench/)维护源文件同步而来；修改这些扩展时先改维护源，再运行构建。其他基础Python源码可在独立仓库内直接修改；从原Workbench工程同步基础代码时使用`--source-root`，避免覆盖未回填的修改。
