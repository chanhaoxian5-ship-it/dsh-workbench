# 工作台网页：页面、样式与交互

这里是用户真正打开的完整工作台网页。它由随包Python服务提供，与DSH设置页是两个不同界面；设置页的代码在[lib/client.js](../../../lib/client.js)。

| 文件 | 具体负责什么 | 常见修改场景 |
|---|---|---|
| `index.html` | 页面基本结构、导航、连接表单、详情弹窗及脚本/样式加载入口。 | 添加页面容器、改基础文案或确认资源入口。 |
| `app.css` | 全局视觉与布局：颜色、文字、按钮、卡片、表格、弹窗和响应式规则。 | 调间距、字号、对比度或手机布局。 |
| `app.js` | 应用状态与请求层；连接/断开、认证HTTP、首页、发现、关注操作、弹窗和各页面协调。 | 改连接流程、请求错误处理或页面间数据联动。 |
| `auth-ui.js` | 项目访问权限弹窗：选择目录、只读/读写、生成配置、展示期限和撤销；不把秘密保存在网页存储。 | 修改项目授权管理流程。 |
| `experience.js` | 项目、文件、版本等主要体验页面的组织，协调真实资料页面与预览组件。 | 改页面组织、详情打开方式或页面返回路径。 |
| `projects.js` | 真实项目资料页面及登记/查询流程，与项目API对接。 | 改真实工作空间、文件、记录、计划等资料的读写展示。 |
| `catalog.js` | 预览样例与previewApi。演示数据与真实API隔离，不写日常数据库。 | 修改演示内容；不能在这里伪装真实项目接入。 |
| `stages.js` | 阶段轨、里程碑卡、连线、展开状态、滚轮/拖拽牵引等双轨交互。 | 接入board数据或调整阶段板交互；保持已验几何和滚动行为。 |
| `stages.css` | 双轨概览的节点、连线、版本卡、文件条及手机布局。 | 仅修改双轨组件外观，避免散落到全局样式。 |
| `motion.js` | 按钮保存反馈、转场、滚动和其他动效辅助，处理减少动态效果偏好。 | 改交互反馈与动画时序，避免阻塞真实操作。 |
| `motion.css` | 与动效配套的状态样式、关键帧和减少动态效果规则。 | 调动效外观和反馈状态。 |
| `launch.js` | 插件专用连接引导；清除URL片段、兑换一次性票据，换取持久 Cookie 并恢复连接。 | 改设置页打开工作台后的自动连接流程；维护源在`lib/launch.js`。 |
| `icons/icons.js` | 原有SVG图标路径与文件类型标记。 | 改文件类型等基础图标。 |
| `icons/kit-icons.js` | 扩展业务图标资产；由页面按名字选取。 | 增加版本、任务、反馈等业务图标。 |
| `icons/*.svg` | 独立SVG及sprite资源，属于网页内图标。 | 修改页面内图标；不是DSH插件列表图标。 |
| `landscape.svg` | 工作台界面的山水装饰图。 | 更换页面装饰，不影响数据来源。 |

DSH插件列表里的W标志由根目录[assets](../../../assets/)与`package.json.icon`配置。不要把它和本目录的业务图标混淆。

本目录没有独立npm构建步骤。启动随包后端即可查看；后端只开放白名单资源，增加新的JS/CSS文件时要同时检查`server.py`中的ASSETS。双轨组件的真实board映射仍是后续工作，不能把这里存在完整界面等同于所有业务链路已接通。
